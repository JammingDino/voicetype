Dictate into any window on Windows. Speech recognition runs on your own PC; nothing is sent to the cloud.

### Install

1. Download **voicetype-setup.exe** below and run it. Windows may say *"Windows protected your PC"* because the app isn't signed: click **More info → Run anyway**.
2. Click **Yes** to install. It goes in your user folder (no admin needed), with a Start menu shortcut. Already installed? It updates itself; you don't need this file again.
3. On **Models**, download *Base (English)* (148 MB). With an NVIDIA card, also download the GPU engine (670 MB); it makes transcription near-instant.
4. Click into any text box and hold **Ctrl + Alt + Space** while you talk. Let go and the text is typed for you.

### Pages

| | |
|---|---|
| **Shortcut** | pick new keys (click the box, press them); hold to talk or press to start |
| **Hands-free** | stop on silence, type each phrase as you pause, say "hey jarvis" to start |
| **Microphone** | choose the mic and how loud counts as speech |
| **Output** | paste or type keystrokes |
| **General** | run at startup, tray, floating indicator, updates |

Closing the window keeps voicetype in the tray; right-click the tray icon → **Quit** to exit. Uninstall from **Settings → Apps → Installed apps**.
